# 双语实验测试计划 / Bilingual Experiment Test Plan

## 要验证什么 / What this tests

系统是否能把新材料与旧假设和决定建立可追溯的候选关系，同时承认不确定性，并把最终判断留给对应专业人员。

## 五项核心测试 / Five core tests

1. **相关变化：**LS-S004 是否触发 LS-A001 与 LS-D001 的复核，同时避免声称共享准备中心必须取消。
2. **跨专业条件：**LS-S005 是否找到设备条件对 LS-A002 与 LS-D002 的潜在影响，同时避免判断设备能否安装。
3. **意图连续性：**LS-S006 是否挑战 LS-A003，但继续保留 LS-I003 的总体目标。
4. **无关信息：**LS-S007 是否保持安静，不产生设计复核提醒。
5. **模糊意见：**LS-S008 是否要求澄清，而不是自行解释“更灵活”的含义。

## 对照方式 / Baseline

将同一批材料交给普通聊天模型，再与本系统比较：来源引用、影响遗漏、错误提醒、不确定性表达和人工修改量。

## 必须保留的失败 / Required failure record

至少保存一次真实模型的错误输出、人工诊断、修改内容和复测结果。不得只展示成功案例。
